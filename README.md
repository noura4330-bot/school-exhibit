# معرض التمكين المدرسي للذكاء الاصطناعي والتحول الرقمي

موقع عربي (RTL) لثانوية أحد بني زيد، إدارة تعليم مكة المكرمة، محافظة القنفذة. يجمع المعرض خطة المبادرة والحوكمة والتدريب والممارسات التعليمية ومشروعات الطالبات والشواهد وقياس الأثر، ويتابع الاستعداد لمتطلبات Microsoft Elevate Showcase School.

> **حالة الموقع:** منشور بتاريخ 24 أكتوبر 2026 كصفحة Artifact خاصة على claude.ai: https://claude.ai/artifact/2HnfXbLfDquohdub8oGeEx (خاصة بصاحب الحساب حتى يُشارك رابطها من قائمة «مشاركة»). ويعمل محليًا أيضًا.

### الفرق بين النسخة المنشورة والنسخة المحلية

- كل زائرة ترى بياناتها هي فقط، لأن البيانات تُحفظ في متصفحها.
- الطباعة المباشرة غير متاحة في النسخة المنشورة. يُنزَّل التقرير بصيغة HTML ثم يُطبع من المتصفح.
- التنزيلات تمر عبر نافذة تأكيد من المنصة. بعض امتدادات الملفات المرفوعة (مثل .ppt و.doc) قد لا تُنزَّل من النسخة المنشورة.
- لإعادة بناء ملف النشر: `npm run build` ثم `node scripts/build-artifact.mjs`. الناتج في `artifact/index.html`.

## التشغيل

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
npm run dev        # نسخة التطوير على http://localhost:5173
npm run build      # بناء النسخة النهائية في مجلد dist
npm run preview    # معاينة النسخة النهائية
```

مجلد `dist` نسخة مبنية جاهزة. يمكن رفعه إلى أي استضافة ثابتة، أو تشغيله محليًا بخادم بسيط مثل `npx vite preview`. لا يعمل بالنقر المزدوج على `index.html` مباشرة لأن المتصفح يمنع تحميل الوحدات من `file://`.

## البنية

```
src/
  data/        الأنواع، والقوائم والحالات، وبيانات البداية، والمخزن، والحسابات المشتقة، والتقارير
  lib/         التوجيه، وتخزين الملفات (IndexedDB)، والأدوات المساعدة
  components/  مكونات قابلة لإعادة الاستخدام: الهيكل، والنماذج، والسجلات، والتنبيهات، والفلاتر
  pages/       صفحة لكل عنصر في قائمة التنقل (12 صفحة)
  styles/      رموز الهوية (tokens.css) وتنسيق الواجهة والطباعة (app.css)
```

البيانات منفصلة عن العرض: كل الأرقام في الرئيسية والتقارير تُحسب في `src/data/selectors.ts` و`src/data/reports.ts` من السجلات الموجودة فعلًا.

## أين تُحفظ البيانات؟

للموقع وضعان:

- **الحفظ المركزي (Supabase)**: يعمل متى وُضع رابط المشروع ومفتاحه العام في `src/cloud.config.ts`. تُحفظ البيانات في قاعدة بيانات مشتركة، والملفات في تخزين خاص بلا روابط عامة، ولا يظهر شيء قبل تسجيل الدخول بحساب منحته مديرة النظام صلاحية. الصلاحيات مفروضة في القاعدة نفسها (سياسات RLS ودوال في `supabase/schema.sql`)، لا في الواجهة وحدها.
- **الحفظ المحلي**: حين يبقى الإعداد فارغًا (ونسخة الصفحة الواحدة على claude.ai دائمًا). السجلات في `localStorage` والملفات في `IndexedDB` داخل متصفح الجهاز نفسه، ولا تظهر على جهاز آخر.

الأدوار في الحفظ المركزي: مديرة النظام (كل شيء مع إدارة الصلاحيات)، والمستخدم المصرّح له (إضافة وتعديل وحذف)، والمشرفة (اطلاع فقط)، والحساب الجديد يبقى «بانتظار منح الصلاحية» ولا يرى شيئًا.

لا يوضع مفتاح `service_role` أو أي مفتاح سري في الموقع أبدًا؛ النشر على GitHub Pages يتوقف تلقائيًا إن وُجد (`scripts/check-secrets.mjs`).

## طريقة إضافة الشواهد

1. افتحي «الشواهد والأدلة» ثم اضغطي «إضافة شاهد».
2. اكتبي العنوان، واختاري النوع والتصنيف وحالة المراجعة ومستوى الحساسية.
3. ارفعي الملف، أو ضعي رابط OneDrive أو SharePoint.
4. وثّقي ما يثبته الشاهد، وكيف يرتبط بالمؤشر، وما الدليل الظاهر داخله.
5. اختاري المؤشرات أو الأنشطة المرتبطة. عند ربط الشاهد بأكثر من مؤشر يصبح «مبرر الربط» مطلوبًا.
6. يمكن أيضًا الربط من الجهة الأخرى: من نموذج الورشة أو الممارسة أو المؤشر عبر قسم «الشواهد».

## النسخ الاحتياطي

من «الإعدادات» ثم «النسخ الاحتياطي والاستيراد»:

- **تصدير البيانات (JSON):** السجلات فقط، وحجمها صغير.
- **تصدير البيانات مع الملفات:** السجلات والملفات المرفوعة في ملف واحد. قد تحتوي هذه النسخة بيانات شخصية، فاحفظيها في مكان آمن.
- **استيراد نسخة احتياطية:** تستبدل كل بيانات الجهاز الحالي بعد طلب تأكيد. تُستخدم أيضًا لنقل المعرض إلى جهاز آخر.

## مؤشرات المقياس الرسمي

لم يُتح فتح AI Transformation Rubric من بيئة البناء، لذلك لم تُنشأ أي مؤشرات من التخمين. أدخليها من «لوحة متابعة الجاهزية»، إما يدويًا أو باستيراد ملف CSV بأعمدة: `المجال، الرمز، نص المؤشر، المستوى، المصدر`. يوجد زر لتنزيل القالب.

## ما الذي يحتاج إلى خدمة خارجية؟

| الوظيفة | الوضع الحالي | ما يلزم |
|---|---|---|
| مشاركة البيانات بين عدة أجهزة أو مستخدمات | متاحة بالحفظ المركزي (Supabase) بعد إعداده | — |
| تسجيل الدخول والصلاحيات | غير موجودة | مصادقة، مثل Microsoft Entra ID |
| حفظ الملفات في السحابة | غير متاح | OneDrive أو SharePoint أو تخزين سحابي |
| التحقق الآلي من عمل الروابط الخارجية | يُفحص شكل الرابط فقط | خادم وسيط، لأن المتصفح يمنع فحص المواقع الأخرى |
| تصدير PDF | عبر «طباعة ثم حفظ بتنسيق PDF» في المتصفح | لا يلزم شيء |

## النشر على استضافة

الموقع ثابت بالكامل، فيكفي رفع محتوى `dist`. من الخيارات المناسبة: Azure Static Web Apps، أو GitHub Pages، أو Netlify.

1. `npm run build`
2. ارفعي محتوى مجلد `dist` إلى الاستضافة.
3. التوجيه يعتمد على `#/`، فلا يلزم إعداد خاص للخادم.

تنبيه: النشر لا ينقل البيانات. كل زائرة سترى معرضًا فارغًا في متصفحها، إلى أن تُضاف خدمة بيانات مركزية. لا تنشري أي ملف يحتوي معلومات حساسة.
